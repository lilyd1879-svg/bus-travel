# 🚌 한국 시내버스 여행 (Korea CityBus Planner)

> **전국 시내버스·농어촌버스 전용 최적 환승 경로 플래너 & 장거리 시내버스 완주 내비게이션**

기차나 고속버스 없이 **오직 순수 시내버스와 마을·농어촌 버스만으로 전국을 횡단·종단**하는 여행자들을 위한 정밀 버스 환승 경로 탐색 및 시각화 플랫폼입니다.

---

## 🚀 실시간 웹 체험 링크 (Live Demo)
👉 **https://lilyd1879-svg.github.io/bus-travel/**

---

## ✨ 주요 기능
- **순수 시내버스 환승 알고리즘**: 시외버스/기차 배제, 전국 지자체 시내·농어촌 버스 환승 연결망 최적화
- **실시간 지도 시각화**: Leaflet 지도 기반 정류장 핀포인트 및 경로 트래킹
- **도보 구간 및 첫차/막차 고려**: 도보 연결 거리 최소화 및 지자체 경계 환승 지점 자동 매칭
- **반응형 모바일 UI**: 여행 중 스마트폰 브라우저에서 바로 사용할 수 있는 직관적인 내비게이션

---
